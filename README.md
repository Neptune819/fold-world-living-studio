# Fold World Living Studio

Minghao Liu’s personal Living Studio, published with GitHub Pages.

- Explore three existing Fold World scenes.
- Open the From the Abyss final-project proposal, storyboards, reference gallery and video tests.
- Try Moon Tides, a Creative Coding 2.0 artwork using MediaPipe hand landmarks. Camera access is optional and frames are processed locally in the browser.
- Read the dated Week 09 working log.

No build step or backend is required. Serve this directory with any static HTTP server. The hand-tracking runtime and model are included locally; see the artwork’s third-party notice for sources and licenses. Browsers require HTTPS or localhost for camera access.

Edits made through the on-page archive editor are stored only in that visitor’s browser. Public updates are made through this repository.
